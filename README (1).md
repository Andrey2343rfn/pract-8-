# Практична робота № 8. Обробка та аналіз IoT-даних в openHAB

## Середовище
openHAB 4, RRD4j Persistence, Basic UI, macOS.

## Виконані завдання
Налаштовано віртуальні датчики температури та вологості, правила статистичного аналізу, виявлення температурних аномалій, моніторинг доступності пристроїв та графіки за годину й добу.

## Результати
Середня вологість: 55 %. Погодинна середня температура: близько 27 °C. Перевірено зміну станів ON/OFF та попередження про аномалії. Повторний стрес-тест: 300 успішних оновлень, 0 помилок.

## Використання штучного інтелекту
Інструмент: ChatGPT (OpenAI).
Мета: допомога з конфігурацією sitemap, правилами openHAB, REST-запитами, діагностикою та оформленням звіту.
Приклади запитів: «дай мені нормальний код для цього файла», «перевіримо погодинне усереднення температури», «підготуй звіт».
Використані фрагменти: приклади конфігурації sitemap, команди curl, рекомендація щодо оновлення Average_Humidity, текст звіту.
Власна перевірка: запуск openHAB, надсилання тестових даних, перевірка значень у REST API та Basic UI, перевірка журналів, повторний стрес-тест і внесення виправлень до правил.
